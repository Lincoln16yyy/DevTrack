# Arquitetura e decisões técnicas

Registre aqui decisões relevantes depois de discutidas e aprovadas.

Para cada decisão importante, prefira um registro com:
- Contexto e problema;
- decisão escolhida;
- alternativas consideradas;
- vantagens, custos e limitações;
- consequências;
- data e estado (proposta/aprovada/substituída).

Não inventar decisões antes da inspeção e discussão com o estudante.
