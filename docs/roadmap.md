# Roadmap de aprendizagem e produto

> Documento inicial. O agente deve propor uma versão curta com base no estado real do repositório e aguardar aprovação antes de alterar este plano.

## Princípios

- Priorizar competências úteis em vagas júnior e presentes no currículo.
- Trabalhar em issues pequenas, idealmente concluíveis em uma sessão.
- Aprender conceitos antes de implementar.
- Entregar fatias demonstráveis, com critérios de aceitação e testes.
- Não introduzir várias tecnologias novas na mesma etapa sem necessidade.
- Incluir preparação para entrevistas e revisão espaçada.

## Etapas propostas — ainda não aprovadas

1. Inspeção do ambiente, requisitos e primeira fatia vertical.
2. Persistência e API mínima, com testes.
3. Interface React/TypeScript integrada à API.
4. Validação, tratamento de erros e qualidade.
5. Autenticação e autorização, quando justificadas.
6. CI, documentação e deploy.
7. Revisão técnica, exercícios independentes e preparação para entrevistas.
