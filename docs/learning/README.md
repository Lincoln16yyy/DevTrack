# Diário de aprendizagem

Este diretório registra o que foi estudado e demonstrado, não apenas o código implementado.

## Regras

- Registrar cada issue de aprendizagem em um arquivo próprio, por exemplo `ISSUE-001-nome-do-assunto.md`.
- Separar explicações do agente das respostas e demonstrações do estudante.
- Não marcar um conceito como dominado porque a funcionalidade foi concluída.
- Anotar dificuldades, erros reais, como foram investigados e como foram corrigidos.
- Revisitar conceitos anteriores em sessões futuras.

## Níveis de domínio

1. **Reconhece:** identifica o conceito quando explicado.
2. **Explica:** descreve com as próprias palavras.
3. **Aplica:** resolve um exemplo sem copiar a solução.
4. **Defende:** responde a perguntas complementares e justifica trade-offs.

O nível só muda com evidências observáveis do estudante.
